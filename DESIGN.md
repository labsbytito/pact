# Pact: a little intention, a real next step

The attached product brief defines behavior. The new visual direction supersedes the older DESIGN.md in Downloads; do not read that file.

Pact is one approachable companion with conversation threads for intentions. It should be as familiar as Messages, with contextual source attachment and a next action inside the conversation. No analytics dashboard and no multi-agent roster for users.

Material: pearl, parchment, subtle frosted chrome, restrained coral accent. High contrast charcoal text. Body text in narrow side panel around 17px. System sans or locally bundled legible type. Original small sculpted coral companion, two simple eyes, one folded corner/tip; expressive through silhouette, short state transitions and gaze. Never emoji, robot clip art, or a copied branded asset. No perpetual motion.

Home: welcoming character, 'That thing you’ve been meaning to do.' Source capture card; light curiosity starters; a proper message composer anchored at the bottom. My Pacts is a calm list/grid on wide screens. Narrow panel shows compact top navigation and one continuous conversation. Settings and source inspection are focused sheets.

Use opacity for secondary chrome; opaque reading surfaces. Warmth through spacing/material, never dim body text. Render at 360, 420 and desktop widths. Reduced motion and keyboard focus required.

Division: main chat owns App.tsx/lib/server until explicitly handed off. Cursor owns entrypoints/sidepanel/style.css and may create character-only assets under public/character. Separate Codex chat writes REVIEW.md only. Claude Code investigates Fo integration and writes FO-INTEGRATION.md only initially. No shared-file edits in parallel.
