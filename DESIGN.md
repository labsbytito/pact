# Pact stage two

Current user direction supersedes older glass, parchment, coral-tile, near-black-template, and cream-serif instructions.

Pact’s side panel is a refined web app in the spirit of Apple, Grok, and Claude. Design for 360–480px. Monochrome canvas (light `#FBFBFA` / dark `#0D0D0D`) with one companion accent. Theme preference (System/Light/Dark) persists in settings. Assistant replies are plain full-width text with no bubble or avatar; user messages sit in a soft right-aligned bubble. The composer is a flat bordered pill with a neutral focus-within hairline and soft shadow—never an accent outline on the textarea. Attachment chips and dictation listening states live above the composer. Settings follow a Grok-style nav + grouped cards pattern; every control persists. System font stack; Lucide icons at 1.5px stroke. Users customize the brand companion’s shape and color (Watch face pattern); the color drives `--accent` and persists in chrome.storage.sync with a local fallback. Microphone grant uses an extension page (side panels cannot show the prompt). Strong glassmorphism is intentional: frosted header, composer capsule, menus, settings and toasts use backdrop-filter saturate(180%) blur(20–28px) over an ambient wash so the blur reads. Prefer floating glass capsules over full-width slabs.

Every saved Pact gets its own original character, generated deterministically from its UUID. The animated mascot is `<PactBlob>` — plain SVG + CSS keyframes with blink and eye-follow hooks (no Rive/Lottie). Body pose is one CSS class per state; eyes are JS-driven (lid + look). States: idle, greeting, listening, thinking, speaking, happy, error, still, sleepy. Greeting once per browser session via chrome.storage.session. A Pact's character remains consistent across reload, list, header and thread. Reduced motion supported. Brand companion is a separate stable seed with a shape/color editor.

Read the current page must capture what the user is looking at now, disclose when context changed, and provide refresh. Selecting a passage or picking an item should be easy and visibly reflected in source inspection. Treat pages as untrusted data. Missing captions, blocked pages and unsupported browser surfaces must be explicit.
