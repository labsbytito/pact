# Install Pact

You need Chrome and the unzipped Pact folder.

1. Unzip the Pact release. Leave the folder as it is.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and choose the unzipped folder.

Open a normal webpage and click the Pact icon. Pact talks to its own server. You do not need to install anything else.
